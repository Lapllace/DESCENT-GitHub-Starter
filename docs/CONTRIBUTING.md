# Contributing to DESCENT

## Workflow
1. Find or create a GitHub Issue.
2. Assign one task owner.
3. Create a focused branch, e.g. `feature/threat-scanner`.
4. Read `AGENTS.md` and relevant design documents.
5. Implement only the agreed scope.
6. Run relevant tests and record exact results.
7. Open a Pull Request linked to the Issue.
8. Request review before merging.

## AI-assisted work
AI tools are welcome, but generated suggestions are not automatically approved decisions. Identify the AI tool/model when known and summarize work in the PR or a contribution report.

## Asset rules
Verify license and attribution requirements. Record source and license for third-party assets. Never commit secrets or personal data. Coordinate edits to shared Unreal binary assets.
